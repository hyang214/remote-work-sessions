# Governance

Remote Work Sessions is maintained through public GitHub issues, pull requests,
reviews, and releases.

## Roles

- Contributors propose changes and help validate behavior.
- Maintainers triage issues, review and merge changes, manage repository
  settings, respond to security reports, and publish releases.

The current maintainers are the users with write or maintain access in the
GitHub repository. Repository access, rather than a copied name list, is the
source of truth.

## Decisions

Routine decisions are made through pull-request review. Changes to the public
CLI, configuration format, security model, supported platforms, or release
process should include the alternatives and compatibility impact in the issue
or pull request. Maintainers seek consensus; when consensus is not possible, a
maintainer records the decision and rationale publicly.

## Changes in Maintainer Access

Existing maintainers may invite a contributor who has shown sustained,
constructive work and sound security judgment. Access may be removed for
inactivity, at the maintainer's request, or for a Code of Conduct or security
violation. At least one other maintainer should review access changes whenever
the project has more than one maintainer.
