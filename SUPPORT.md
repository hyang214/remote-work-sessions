# Support

Use the public project channels for help:

- Read the [setup guide](docs/SETUP.md) and [scenarios](docs/SCENARIOS.md).
- Run `rws doctor` and include its non-sensitive output in a bug report.
- Search existing [GitHub issues](https://github.com/hyang214/remote-work-sessions/issues).
- Open a bug report when the problem is reproducible on a supported path.

Before posting, remove credentials, private hostnames and addresses, usernames,
device names, absolute home paths, and private repository or registry URLs.

Security vulnerabilities must be reported through
[GitHub private vulnerability reporting](https://github.com/hyang214/remote-work-sessions/security/advisories/new),
not through a public support request. See [SECURITY.md](SECURITY.md).

Support is best effort. The project does not provide a private support SLA.
